# 취미 감상문

취미로 접한 작품이나 활동에 대한 감상을 작성하고 `type: review`를 사용한다. 고정 목차나 본문 양식은 사용하지 않는다. 실제 확인한 원작·원문과 사용자가 제공한 감상을 읽고, 그 내용과 형식에 맞춰 글마다 전개를 정한다.

원작의 구성을 기계적으로 옮기거나 소개·기억·평가 순서를 모든 글에 반복하지 않는다. 사용자가 짚은 장면이나 생각에 맞는 서술을 선택하며, 다른 사람의 감상문을 사용자의 경험으로 바꾸지 않는다.

작품의 사실 정보와 개인적인 해석을 구분한다. 사용자가 제공하지 않은 관람·독서·플레이 경험이나 감정을 만들어 넣지 않는다. 내용 누설이 있으면 본문 앞에서 알린다. 개인적 느낌에는 외부 근거를 요구하지 않으며, 출처 목록에는 사용자의 원본 감상 메모를 연결할 수 있다.

검토한 글만 [공개 목록](../manifest.json)에 `/reviews/<slug>`로 등록한다. 목록과 상세 화면은 프로젝트·기술 공부와 구분한다. 이 README와 미등록 초안은 출력하지 않는다.

# 기술 공부

공개할 기술 학습 글을 이 폴더에 작성하고 `type: study`를 사용한다. 본문 양식은 사용하지 않는다. 원문을 실제로 읽고 목차와 설명의 전개를 파악한 뒤, 해당 원문에 맞는 순서와 소제목으로 글을 따로 구성한다.

질문·실험·한계 절을 모든 글에 일괄적으로 붙이지 않는다. 원문의 논지를 정확히 전달하는 데 필요한 내용을 선택하고, 출처와 확인 범위는 문맥이나 말미에 표시한다. 직접 하지 않은 실험을 수행한 것으로 쓰지 않는다.

단순 자료 수집은 `raw/`, 재사용할 분석은 `wiki/`에 남긴다. 외부 자료의 주장을 본인의 실무 성과로 표현하지 않는다.

검토를 마친 글만 [공개 목록](../manifest.json)에 `/study/<slug>`로 등록한다. 프로젝트와 취미 감상문은 각각 별도 공간에 작성한다. 이 README와 미등록 초안은 사이트에 포함되지 않는다.

게임·AI 자료 모음의 원문을 바탕으로 작성한 글 21편이 있다. 각 글에 원문 링크·작성자·발행일과 읽은 범위를 표시했다. 내부 [수집 결과](../../docs/game-ai-ingestion.md)에는 원문 보관 제한과 추가 확인이 필요한 자료를 기록했다.

기존 21편도 보관 원문을 다시 읽고 각 원문의 전개에 맞춰 재작성했다. [글별 구성과 재독 범위](../../docs/study-rewrite-report.md)에 확인 기록을 남겼다.

# Wizard가 게임 상태를 영상으로 연결하는 과정

## 골격과 기하를 짝지은 데이터

Wizard는 화면의 깊이·높이와 캐릭터 골격을 같은 카메라에서 렌더링해 영상과 짝짓는다. 저자들은 805개 장면·178개 캐릭터의 56.1시간 데이터를 구성했다. 캐릭터 슬롯을 참조 이미지와 연결해 움직임 조건과 외형을 나눈다.

## 상태를 바꾸는 제어 계층

입력 이미지에서 장면을 복원하고 캐릭터를 리깅한 뒤, 호환되는 골격의 모션을 검색·리타기팅한다. 자연어 지시는 미리 정의한 기하 연산을 조합하는 프로그램으로 바꾼다. 전투에서는 공유 상태의 위치·체력·행동 단계·쿨다운을 읽고 공격을 선택하며, 규칙 기반 제어기가 피격과 피해를 판정한다.

## 상태를 따라 그리는 생성 계층

생성 모델에는 갱신한 상태의 프록시를 전달한다. 캐릭터별 마스크는 외형 정보가 다른 캐릭터로 섞이는 것을 줄이고, 공간 기억은 과거 프레임과 현재 시점을 세계 좌표로 연결한다. 논문은 학습 뒤 2단계 생성으로 증류한 실시간 변형도 평가한다.

복원 오류도 프록시로 전달된다. 부록 G는 호환 모션 부족, 긴 실행의 일관성 저하, 잘못된 리깅·기하가 프록시로 전파되는 문제를 한계로 설명한다.

Yuzhe Wu 외의 [Wizard v2](https://arxiv.org/html/2610.40339v2)(2026-11-17)에서 3~5장과 부록 G, [공식 설명](https://wyzardwu.github.io/wizard/)을 다시 읽었다. 프로젝트 페이지는 이전 저자 표기를 유지한다. 영상 시청·모델 실행은 하지 않았다.

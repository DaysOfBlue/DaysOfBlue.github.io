# UnityBench의 프로젝트 구성과 엔진 평가 과정

## 빈 저장소 대신 수정할 Unity 프로젝트

UnityBench-Mini3D의 77개 과제는 목표·맥락·제약·리소스 설명과 초기 Unity 프로젝트를 제공한다. 씬 구성과 애니메이션 등 7개 개발 역량으로 분류하며, 기존 참조와 동작을 보존하면서 요구사항을 구현하게 한다. 제작진은 정답 프로젝트가 전부 통과하고 초기 상태는 통과하지 않는지 확인해 과제와 검사를 검토했다.

## 작업 종료 후 주입하는 평가기

에이전트에게는 1,178개 마일스톤 검사를 숨긴다. 작업이 끝나면 생성된 라이브러리 상태를 초기화하고 재임포트·컴파일한 뒤 평가기를 넣는다. EditMode는 계층·컴포넌트·직렬화된 참조를, PlayMode는 물리·애니메이션·UI의 실행 동작을 확인한다.

각 과제 점수는 통과한 마일스톤의 비율이며 전체 점수는 과제별 평균이다. 컴파일 실패, 에디터 실행 실패와 구현 실패를 따로 기록하므로 부분 완성을 진단할 수 있다.

## 평가에서 드러난 공간 오류

결과 분석에서는 씬 구성이 상대적으로 어려웠고, 점수가 높은 구성에서도 배치·크기 같은 공간·수치 오류가 남았다. 엔진 도구를 제거한 비교에서는 점수가 낮아졌고, GUI 조작을 추가해도 일관된 향상은 없었다. 이는 해당 과제·모델·실행 도구 조합의 결과다.

Yijun Zhou 외의 [UnityBench-Mini3D v1](https://arxiv.org/html/2610.35980v1)(2026-10-26)에서 1·3·4·5장을 다시 읽었다. 부록 전체와 벤치마크 실행은 검증하지 않았다.

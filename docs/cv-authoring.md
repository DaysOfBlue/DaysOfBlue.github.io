# 소개 페이지와 CV 작성

[CV 양식](../templates/cv.md)은 `content/profile.md`를 작성할 때 사용하는 빈 초안이다. 현재 소개 초안에는 확인된 신원·이력이 없으므로 공개하지 않는다. 기본 홈페이지와 디자인 미리보기의 소개 페이지에는 별도의 빈 CV 화면을 표시한다. 이 화면은 초안 파일의 내용을 읽지 않는다.

## 작성 방법

1. 기존 소개 초안을 보존하면서 양식에서 필요한 항목을 가져온다. 이름과 한 줄 소개를 작성하고, 메인의 자기소개에 쓸 짧은 문장을 `summary`에 넣는다.
2. 경력·학력·프로젝트는 각각 최신순으로 작성한다. 항목을 여러 개 적을 때에는 해당 묶음을 반복한다. 웹 화면은 Markdown에 적은 순서를 따른다.
3. 프로젝트에는 기간, 본인의 역할과 기여, 문제와 접근, 확인된 결과를 짧게 적고 상세 글이나 근거를 연결한다. 팀 전체 성과와 본인의 기여를 구분한다.
4. 사용 기술에는 실제 활용 범위를 쓴다. 경험이 없는 항목, 불필요한 세부 항목과 빈 입력란은 삭제한다. 연락 수단·학점·어학 성적 등은 공개할 필요가 있는 것만 남긴다.
5. 날짜의 `YYYY-MM-DD`를 실제 작성·수정일로 바꾸고, `sources`에는 이력의 근거로 등록한 출처 ID를 넣는다. CV 작성법 글은 개인 이력을 증명하는 자료로 쓰지 않는다.
6. 사실·오탈자·기간·명칭을 대조한 뒤 `reviewed`로 바꾸고 공개 목록에 `/about` 경로로 등록한다. 검토 전 초안은 빌드에 포함하지 않는다.

현재 양식은 내용을 입력하는 Markdown 파일이다. 웹 입력 폼이나 PDF 출력 기능은 포함하지 않는다. 검토한 프로필을 등록하면 소개 페이지에는 해당 본문을 표시하고 빈 양식을 숨긴다.

## 참고 자료와 적용 범위

kisoo의 [CV(Curriculum Vitae) 작성하는 방법(feat. 대학원 준비)](https://m.blog.naver.com/kisooofficial/223331186064)(2024-01-23)의 본문을 확인했다. 객관적인 서술, 경력과 프로젝트의 최신순 배치, 제3자 관점에서의 검토를 참고했다. 학력·연구 경험·프로젝트·수상·기술 항목도 양식에 반영했다.

원문은 대학원 지원용 CV에 관한 개인의 조언이다. 원문의 필수 항목 구분, 연락처 공개, 분량 권고를 모든 개인 홈페이지의 의무로 적용하지 않았다. 경력과 기술을 담는 웹 소개 양식으로 조정한 것은 이 프로젝트의 선택이다. 연결된 외부 CV 양식이나 원문 속 이미지 디자인을 복제하지 않았다. 확인 범위는 [내부 출처 기록](../wiki/sources/kisoo-cv-writing.md)에 남겼다.

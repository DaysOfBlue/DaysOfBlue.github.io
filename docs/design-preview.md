# 홈페이지 디자인과 별도 미리보기

DevBlog 기반 디자인과 미디어·출처 표시를 기본 홈페이지에 적용한다. `npm run build`가 만드는 `dist/`는 사이트 루트 경로를 사용한다. 글꼴 비교와 기능 예제는 별도 미리보기로 유지한다. 원격 등록·push·배포는 수행하지 않는다.

## 실행 위치

| 명령 | 위치와 용도 |
| --- | --- |
| `npm run build` | 기본 홈페이지를 `dist/`에 생성 |
| `npm run dev` | [기본 홈페이지](http://127.0.0.1:4173/) |
| `npm run edit` | [기본 홈페이지 편집기](http://127.0.0.1:4175/__editor/). 저장 시 `dist/` 재생성 |
| `npm run build:preview` | `build/devblog-preview/`에 비교용 결과 생성 |
| `npm run dev:preview` | [별도 미리보기](http://127.0.0.1:4174/preview/devblog/) |
| `npm run edit:preview` | [미리보기 편집기](http://127.0.0.1:4176/__editor/). 저장 시 별도 미리보기 재생성 |

서버는 `Ctrl+C`로 종료한다. Markdown이나 설정을 직접 수정한 뒤에는 해당 빌드 명령을 실행하고 브라우저를 새로 고침한다. 자동 파일 감시와 재빌드는 제공하지 않는다.

## 공통 화면

DevBlog 원본의 280px 사이드바, 원형 프로필 영역, 가운데 정렬된 상단 영역과 최대 820px 본문 컨테이너를 사용한다. 사이드바는 짙은 회색, 상단은 밝은 회색, 글 목록은 흰색이다. 데스크톱 썸네일은 96×72px, 모바일은 72×58px다. 992px 아래에서는 상단 메뉴 버튼으로 전환한다. 이메일 입력과 구독 폼은 포함하지 않는다.

메뉴는 홈·소개·프로젝트·기술·취미 순서다. 홈 상단에는 공개 프로필의 `summary`만 표시하며 요약이 없으면 소개 페이지로 안내한다. 프로필이 미공개이면 준비 중 안내만 둔다. 소개에는 공개 프로필 본문을, 공개 프로필이 없으면 내용 없는 CV 양식을 표시한다. 미공개 프로필 초안은 읽어 표시하지 않는다.

상단 아래에서 프로젝트·기술·취미의 한 줄 목록을 전환한다. 기본 선택은 프로젝트이며 주소 해시가 있으면 해당 영역을 연다. 클릭과 방향키·Home·End·Enter·Space로 전환하고 JavaScript가 없어도 세 영역과 일반 링크에 접근할 수 있다. 각 목록은 `created` 최신순으로 최대 5개를 표시한다. `featured` 필드는 호환 메타데이터로 유지하며 별도의 대표 프로젝트 영역은 없다.

탭 아래와 분야별 목록에는 세부 카테고리와 전체 공개 글 기준의 개수를 표시한다. 카테고리 페이지에서는 최신 5개 밖의 글도 볼 수 있다. 설정한 빈 카테고리도 표시한다. 이름과 순서는 [설정 파일](../content/categories.json), 글의 분류는 frontmatter의 `category`로 관리한다. [카테고리 안내](categories.md)를 참고한다.

프로젝트·기술 공부·감상문은 각각 독립 목록과 상세 페이지를 사용한다. 소개·프로젝트·감상문에는 아직 공개 콘텐츠가 없어 빈 상태를 표시한다. [빈 CV 양식](../templates/cv.md)과 [작성 안내](cv-authoring.md)는 실제 이력을 준비하기 위한 문서다. 가상의 경력이나 성과로 빈 화면을 채우지 않는다.

실제 썸네일을 제공하기 전에는 회색 SVG 표지를 사용한다. 내용의 근거가 되는 이미지가 아니므로 빈 대체 텍스트를 사용한다.

## 기본 홈페이지와 비교용 화면의 차이

기본 홈페이지는 Noto Sans KR을 사용하고 미리보기 표시, 글꼴 비교 막대와 `noindex` 메타 태그를 넣지 않는다. 글꼴은 외부 CDN 대신 정적 자산으로 제공하며 코드 블록은 고정폭 글꼴을 유지한다.

별도 미리보기는 기본 Noto Sans KR과 Pretendard를 비교할 수 있다.

- [Pretendard로 열기](http://127.0.0.1:4174/preview/devblog/?font=pretendard)
- [Noto Sans KR로 열기](http://127.0.0.1:4174/preview/devblog/?font=noto-sans-kr)

비교 화면의 선택은 `font` 매개변수로 내부 링크에 전달한다. 실제 글꼴 로드 완료 상태를 표시하며 JavaScript가 없으면 Noto Sans KR을 사용한다. 글꼴의 이용 조건은 [글꼴 기록](../src/preview/fonts/NOTICE.md)에 있다.

[미디어 예제](http://127.0.0.1:4174/preview/devblog/media-lab/)와 생성한 예제 이미지·3초 영상은 별도 미리보기에서만 제공한다. 공개 글 목록에는 등록하지 않으며 기본 홈페이지와 기본 편집기에는 포함하지 않는다. 별도 미리보기에는 `noindex, nofollow`를 붙인다. 이 메타 태그는 접근 제한이나 비밀 보호 기능이 아니다.

## 글·문구·미디어 편집

본문은 Markdown, 화면 문구는 [content/site.json](../content/site.json), 첨부 표시와 하단 출처는 `content/post-settings/<게시물-id>.json`에서 관리한다. 기본 편집기에서 첨부의 너비·비율·정렬·위치·캡션과 출처를 조절하고 `파일에 저장`을 누르면 JSON을 저장하고 `dist/`를 다시 생성한다. 파일 업로드는 첨부와 초기 표시 설정을 바로 저장한다. [작성 안내](media-authoring.md)에 문법과 저장 절차를 정리했다.

기술 글 21편의 출처 28개는 기본 홈페이지와 미리보기 모두 글 하단에 표시한다. 원본 Markdown은 유지하고 `referenceBlocks`로 대조한 말미 문구만 화면에서 중복 표시하지 않는다. 본문 중 근거 링크와 의미 설명은 남긴다.

## 구현과 공개 경계

기본 빌드와 미리보기는 공통 DevBlog 렌더러를 사용한다. 공개 로더와 Markdown 렌더러를 재사용하고 DevBlog의 `header`, `navbar`, `profile-section`, `cta-section`, `blog-list`, `row`와 `col` 구조에 콘텐츠를 연결한다. 설정과 디자인 자산은 기존 `src/preview/` 위치를 계속 사용한다.

출력에는 지정한 CSS·메뉴/탭 모듈·SVG·글꼴과 공개 글이 실제 참조한 첨부만 복사한다. 미리보기는 비교용 모듈과 전용 예제를 추가한다. 원자료·내부 문서·초안·편집용 JSON·편집기 코드와 원본 템플릿 폴더는 정적 출력에 포함하지 않는다.

DevBlog의 고정 커밋 HTML과 CSS를 기준으로 사용한다. 원본 HTML은 비교용으로 보존하며 결과에는 홈페이지 콘텐츠로 수정한 HTML만 넣는다. Bootstrap이 포함된 정적 CSS이며 프레임워크나 외부 npm 패키지를 추가하지 않는다. 원본 Bootstrap JavaScript 대신 작은 메뉴 모듈을 사용하고 JavaScript가 없어도 메뉴를 펼친 상태로 제공한다. [출처 기록](../src/preview/vendor/devblog/NOTICE.md)의 이용 조건에 따라 기본 홈페이지와 별도 미리보기 모두 하단의 원 제작자 링크를 유지한다.

## 확인 범위

변경 후에는 `npm run check`, 원자료가 모두 있는 환경에서는 `npm run check:sources`, `npm test`, `npm run build`와 `npm run build:preview`로 구조와 공개 경계를 검사한다. 브라우저에서는 기본 홈페이지의 탭·카테고리·모바일 메뉴·CV·글 하단 출처, 편집기의 저장과 재빌드를 확인한다. 실제 실행 결과는 [작업 로그](../wiki/log.md)에 수행한 범위대로 기록한다.

실제 프로필·프로젝트·감상문·썸네일이 등록되면 해당 콘텐츠의 화면 검토가 추가로 필요하다. 외부 영상 서비스의 실제 재생이나 모든 미디어 형식의 브라우저 호환성을 자동 검사만으로 확인했다고 보지 않는다.

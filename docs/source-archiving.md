# 웹 원문 수집

요약 자료는 출처를 찾는 진입점이다. 공개용 기술 공부 글은 출처 원문을 읽고 작성하며, 원문을 확인하지 못한 부분을 요약의 내용으로 보충하지 않는다.

## 이번 수집의 저장 위치

`raw/game-ai/`의 기존 자료 모음은 그대로 보존한다. 2026-11-18 웹 수집본은 `raw/web/game-ai/2026-11-18/`에 저장한다. 각 출처 폴더의 `original.html` 등은 다운로드한 응답 본문이며 변환·번역·요약을 덧붙이지 않는다.

`capture.json`은 요청 주소, 최종 주소, 수집 시각, 응답 종류, 원본 경로와 SHA-256을 기록한다. HTTP 라이브러리가 압축을 해제한 응답 본문을 저장한다. 연결된 이미지·스타일·스크립트·영상까지 묶은 오프라인 사이트 사본은 아니다.

수집 명령은 이번 날짜의 보관 경로를 사용한다. 후속 수집은 새 배치 경로를 명시하도록 도구를 확장하고 기존 보관본을 덮어쓰지 않는다.

```powershell
node scripts/archive-source.mjs --id src-web-example --url 'https://example.com/article'
```

HTTP 오류나 접근 제한 화면을 정상 원문으로 등록하지 않는다. 공식 원문에서 확인한 대체 주소가 있다면 출처와 경로를 별도로 기록한다. 재수집한 수정판은 새 출처 ID로 보관한다.

## 원문에서 공부 글로

출처 페이지에는 원문 파일과 URL, 작성자·발행일을 어디까지 확인했는지, 주요 논점과 한계를 적는다. 논문의 초록, 본문, 프로젝트 페이지는 서로 다른 확인 범위다. 책의 목차나 일부 장을 읽었다면 책 전체를 읽은 것으로 표현하지 않는다.

기술 공부 글은 원문의 목차·논증·설명 순서를 읽고 해당 자료에 맞게 구성한다. 질문·실험·한계 같은 공통 절을 모든 글에 넣지 않는다. 직접 수행하지 않은 실험을 제안하는 경우에는 수행 결과와 구분한다. 독자가 열 수 있는 원문 링크와 확인 범위는 관련 문맥이나 글 말미에 표시한다. 별도 출처 절을 강제하지 않는다. 원본 사본과 내부 출처 ID는 사이트에 출력하지 않는다.

수집 결과가 제공된 요약과 다르면 원문을 기준으로 글을 작성하고 차이를 wiki에 기록한다. 기존 요약 파일의 내용을 고치거나 오류를 숨기지 않는다.

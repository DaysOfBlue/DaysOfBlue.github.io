# 이미지·영상·출처 편집 테스트

이 페이지는 미디어의 너비와 비율, 캡션과 출처 표시를 확인하기 위한 테스트 예제입니다. 프로젝트나 실무 경험을 설명하는 글이 아닙니다.

## 본문 사이에 이미지 넣기

글은 Markdown으로 작성합니다. 이미지는 아래처럼 문단 사이에 넣을 수 있으며, 브라우저 편집기에서 표시 크기와 비율을 바꿀 수 있습니다.

![본문·미디어·출처를 연결한 편집 예제](/media/preview-media-lab/layout.svg)

이미지 뒤의 본문도 자유롭게 이어서 작성합니다. 원본 그림은 유지하고 화면에 표시되는 배치만 별도 설정 파일에 저장합니다.

## 영상과 설명

아래 영상은 이 편집 기능을 확인하기 위해 생성한 3초짜리 테스트 패턴입니다. 자동 재생하지 않으며 재생 버튼으로 확인할 수 있습니다.

영상 비율과 배치를 확인하는 테스트 패턴입니다.

본문 구성은 글마다 정할 수 있습니다. 하단 출처 영역은 공개용 참고 자료가 있을 때만 표시하며 내부 자료 ID는 출력하지 않습니다.

# 프로젝트 제목

## 목표와 범위

사용자가 확인한 목표와 현재 구현 범위를 적는다.

## 본인 역할과 근거

사용자의 실제 기여를 확인할 자료를 연결한다. 팀 성과와 구분한다.

## 결정과 구현

문제, 선택지, 선택 이유, 실제 구현 산출물을 연결한다.

## 결과와 검증

수행한 검사와 결과를 적는다. 측정치는 방법·환경·조건·한계를 함께 남긴다.

## 미해결 사항

확인할 정보와 다음 작업을 적는다. 추정으로 빈칸을 채우지 않는다.

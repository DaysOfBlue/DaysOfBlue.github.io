# 출처 제목

## 원문과 확인 범위

출처 ID, 원본 경로, 입수일, 알려진 작성자·발행일·URL을 적는다. 모르는 값은 미확인으로 남긴다. 본문·이미지·코드·링크 중 실제 확인한 범위를 구분한다.

## 주요 내용

원문이 말하는 내용을 요약하고 위치나 절 제목을 연결한다. 원문의 주장과 검증된 사실을 구분한다.

## 프로젝트에 적용한 해석

적용 아이디어와 선택 이유를 적는다. 원문에 직접 나오지 않은 해석임을 명시한다.

## 한계와 남은 질문

확인하지 않은 주장, 다른 자료와의 충돌, 추가 검증 항목을 적는다.

## 관련 기록

관련 개념·프로젝트·결정 페이지를 연결한다.

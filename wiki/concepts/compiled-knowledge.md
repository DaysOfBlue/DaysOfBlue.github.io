# 누적 지식과 공개 콘텐츠

원자료에서 읽은 사실과 해석을 문서로 누적하면 다음 작업에서 출처와 기존 결정을 다시 찾을 수 있다. 이 프로젝트는 [LLM Wiki 인사이트](../sources/llm-wiki.md)의 패턴을 포트폴리오 준비에 적용한다. 효과나 유지 비용은 아직 측정하지 않았다.

## 층별 책임

원자료는 입수한 바이트를 보존한다. 원문의 오류와 개정 내용도 기존 파일을 바꾸지 않고 별도 자료나 정정 기록으로 남긴다.

wiki는 원문을 요약하고 관련 개념·프로젝트·결정 문서를 연결한다. 해석이 바뀌면 근거와 갱신 이유를 기록한다. 검증되지 않은 내용은 미확인 상태를 유지한다.

공개 글은 방문자가 읽을 수 있도록 편집한다. 사용자 본인의 경험과 외부 자료의 주장을 구분하고 공개 가능한 근거만 제시한다. 초안은 공개 목록에 등록하지 않는다.

## 출처 추적

원문마다 안정적인 ID와 SHA-256을 기록한다. wiki와 공개 글의 frontmatter는 출처 ID를 참조한다. 링크 검사로 파일 관계를 확인할 수 있지만, 해당 출처가 문장의 주장을 실제로 뒷받침하는지는 원문을 읽어 판단해야 한다.

## 탐색과 유지

[인덱스](../index.md)는 현재 문서를 찾고, [로그](../log.md)는 변경을 추적한다. 모든 페이지를 목록에 실어도 개념 사이의 연결이 충분한지는 따로 확인해야 한다. 의미 검토에서는 관련 문서의 연결과 모순을 살핀다.

## 관련 결정

[자료와 공개 콘텐츠의 경계](../decisions/0001-content-boundaries.md)는 Git 관리 범위와 정적 웹 빌드의 공개 목록을 정한다.

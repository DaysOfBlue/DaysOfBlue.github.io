# Gaussian Evil: PlayCanvas에서 3DGS 장면을 실시간으로 다시 비추기

- **출처·제작자:** Will Eastcott의 프로젝트 README
- **날짜:** 2026-11-18 06:42 KST, GitHub 공개 저장소 생성 시각 기준. 별도 발표 날짜는 확인하지 못했습니다.
- **형식:** 영문 기술 설명과 웹 데모. 아래는 README를 바탕으로 했으며 데모를 실행하거나 영상을 시청한 결과가 아닙니다.
- **원문:** [Gaussian Evil: How it works](https://github.com/willeastcott/gaussian-evil#how-it-works)

## 주요 내용

- 캡처된 조명이 이미 들어 있고 사용하기 좋은 법선이 없는 splat 대신, 복원한 대리 메시에서 스포트라이트와 그림자를 계산합니다. 화면 밖 텍스처에 기록한 조명을 splat의 색에 곱하는 방식입니다.
- 그림자를 만드는 실제 표면과 조명을 받아 splat 가장자리까지 덮는 부드러운 외피를 따로 둡니다. 외피까지 그림자를 만들면 팔다리의 그림자가 지나치게 넓어집니다.
- 팔 앞쪽이 얼굴 가장자리의 조명을 가리는 문제에는 깊이 기준으로 조명 샘플을 고르는 보정 패스를 추가했습니다. 작성자가 적은 비용은 이 데모 기준이며 다른 기기나 장면의 성능을 보장하지 않습니다.

## 프로젝트에 적용한 해석

스플랫 장면에 동적 광원을 더할 때 캡처부터 다시 하는 대신, 그림자와 조명 수신을 각각 독립적으로 시험할 수 있는 사례입니다. 작은 장면에서 손전등 하나를 두고, 앞뒤로 겹치는 실루엣을 움직이며 보정 전후의 프레임 시간과 테두리 오류를 같이 비교해 보세요. 이 글의 방식은 기존 색에 조명을 곱하는 시각 효과이며, 완전한 재질·조명 분리는 아닙니다.

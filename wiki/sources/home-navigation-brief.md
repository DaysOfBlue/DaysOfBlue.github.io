# 자기소개 우선 배치와 기술·취미 페이지 요청

[요청 원문](../../raw/home-navigation-brief.txt)을 읽었다. 자기소개를 메인 맨 위로 옮기고 기술·취미 페이지를 각각 만들며, 메인에서 넘겨가면서 볼 수 있도록 하는 요청이다.

기술은 프로젝트와 기술 공부를 구분해 모으고, 취미는 감상문을 표시하는 구성으로 적용한다. 메인에는 자기소개 다음으로 두 영역의 전환을 제공한다. 실제 소개·경력·취미 경험은 새로 제공되지 않아 초안을 공개하거나 내용을 만들어 넣지 않는다.

구현 기준은 [메인과 분야 페이지 결정](../decisions/0005-home-navigation.md)에 기록한다.

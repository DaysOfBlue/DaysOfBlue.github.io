# 포트폴리오 저장소 요청

## 원문과 확인 범위

2026-11-18 사용자 요청을 [원문 파일](../../raw/portfolio-brief.txt)에 보존했다. 출처 ID는 `src-portfolio-brief`다. 작성자의 실제 이름과 별도 발행일은 제공되지 않았다.

## 확인된 목표

현재 프로젝트 폴더를 홈페이지로 만들어 포트폴리오 공간으로 사용하려 한다. 우선 붙여넣은 인사이트를 기반으로 프로젝트 저장소와 `agent.md` 구성을 요청했다.

## 초기 작업의 해석

기존 Git 저장소를 유지하면서 원자료·wiki·공개 콘텐츠 구조와 작업 규약을 구성한다. Codex가 읽는 `AGENTS.md`를 기준으로 두고 `agent.md`에서 연결한다.

홈페이지 화면의 구체적인 구현이나 원격 배포를 이번 요청의 필수 산출물로 확장하지 않았다. 기술 선택과 디자인을 고정하지 않고 [후속 구현 범위](../../docs/website-plan.md)에 남겼다.

## 아직 제공되지 않은 정보

이름, 직업·이력, 실제 프로젝트와 본인 역할, 성과 근거, 공개할 연락처, 디자인, 호스팅이 없다. 자료 모음의 주제만으로 사용자의 전문 분야를 추정하지 않는다.

# 고정 양식 삭제와 원문별 작성 요청

[사용자 요청 원문](../../raw/source-led-writing-brief.txt)을 읽었다. 기술 공부·감상문 양식을 삭제하고, 앞으로 실제 원문을 읽은 뒤 원문 양식에 맞춰 각기 다른 글을 쓰도록 바꾸라는 요청이다.

적용 범위는 두 본문 템플릿과 향후 작성 지침이다. 기존 공부 글 21편의 일괄 재작성은 요청하지 않았다. 변경 이유와 범위는 [작성 방침](../decisions/0004-source-led-writing.md)에 기록한다.
